### పద్ధతి 1: Render.com ద్వారా ఉచిత 24/7 హోస్టింగ్ (సిఫార్సు చేయబడింది - 2 నిమిషాలు)

1. **ఖాతా తెరవండి**: [https://render.com](https://render.com) లో ఉచితంగా సైన్-అప్ అవ్వండి (GitHub లేదా Google తో).
2. **New Web Service**:
   - పైన కుడివైపు **"New +"** బటన్ నొక్కి **"Web Service"** ఎంచుకోండి.
   - ఈ ఫోల్డర్ (`cloud_deploy`) లోని ఫైళ్లను మీ GitHub రిపోజిటరీకి పుష్ చేసి కనెక్ట్ చేయండి, లేదా **"Deploy from Docker"** ఎంచుకోండి.
3. **సెట్టింగ్స్**:
   - Environment: **`Docker`** (తప్పనిసరి — లోకల్ వీడియో డబ్బింగ్‌కు ffmpeg కావాలి, అది Dockerfile లో ఉంది)
   - Plan: **Free ($0/month)**
4. **Create Web Service** నొక్కండి:
   - 1-2 నిమిషాల్లో Render మీకు ఒక పర్మనెంట్ HTTPS URL ఇస్తుంది (ఉదాహరణకు: `https://ttnotes-backend.onrender.com`).
5. **యాప్‌లో లింక్ చేయండి**:
   - మీ మొబైల్‌లో TT Notes యాప్ ఓపెన్ చేయండి.
   - పైన కుడివైపు ఉన్న **⚡/🟢 సర్వర్ స్టేటస్ బటన్** నొక్కండి.
   - Render ఇచ్చిన URL పేస్ట్ చేసి **"సేవ్ & టెస్ట్ చేయి"** నొక్కండి (ఫ్రీ ప్లాన్ నిద్రలో ఉంటే 30-45 సెకన్లు పట్టవచ్చు).
   - ✅ ఇక మీ ల్యాప్‌టాప్ అవసరమే లేదు! యాప్ ఎప్పుడూ ఆన్‌లైన్‌లో ఉంటుంది!
